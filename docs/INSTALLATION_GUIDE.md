# 💻 PyGrassReal Desktop Installation Guide (Windows)

This document provides a step-by-step installation guide for setting up **PyGrassReal Desktop** on Microsoft Windows.

---

## ⚙️ System Requirements

| Item | Minimum Specification | Recommended Specification |
| :--- | :--- | :--- |
| **Operating System** | Windows 10 / 11 (64-bit) | Windows 11 (64-bit) |
| **Processor (CPU)** | Intel Core i5 / AMD Ryzen 5 | Intel Core i7 / AMD Ryzen 7 or higher |
| **System Memory (RAM)** | 8 GB | 16 GB or 32 GB |
| **Graphics Card (GPU)** | WebGL 2.0 / DirectX 12 compatible | NVIDIA GeForce RTX 3060+ (for large Gaussian Splats) |
| **Storage Space** | 2 GB available SSD | 10 GB NVMe SSD |

---

## 📥 Step-by-Step Installation

### 1. Download Installer
* Visit the official **[Releases](https://github.com/PYGRASSREAL/PyGrassReal-Showcase/releases/latest)** page on GitHub.
* Download **`pygrassreal-windows-setup.exe`**.

### 2. Run Setup Wizard
1. Double-click `pygrassreal-windows-setup.exe`.
2. If Windows SmartScreen appears, click **More info** -> select **Run anyway**.
3. Choose your destination install directory (or keep the default).
4. Select **Create Desktop Shortcut**.
5. Click **Install** and wait for the installer to finish.

### 3. Launch Application
1. Open **PyGrassReal** from your desktop shortcut.
2. Sign in with your PyGrassReal account (or register directly in-app).
3. Start designing with 3D computational tools and AI agents!
